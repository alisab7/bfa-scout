Accepted columns
  • full_name — required, text
  • dob — YYYY-MM-DD
  • national_id — unique; min 5 chars
  • primary_position_code — e.g. AMF, DMF, CB (case-insensitive)
  • nationality_code — ISO alpha-3 (e.g. BRA, MAR, BHR)
  • nationality_status — bahraini / foreign_ancestry / foreign_residency / foreign_other / not_eligible / unknown
  • eligible_from_date — YYYY-MM-DD
  • bahrain_residency_start_date — YYYY-MM-DD
  • current_club_name — matches a clubs.name if possible
  • dominant_foot — right / left / both
  • height_cm — integer, sane range 140-220
  • weight_kg — integer, sane range 40-120

Unknown columns are ignored (with a warning in the preview). Column names are case-insensitive; order doesn't matter.
